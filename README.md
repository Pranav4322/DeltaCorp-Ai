# DeltaCorp-Ai
The Autonomous AI Creator is an AI persona built for the ABTalks Vibe Code Hackathon that genuinely operates on its own after a single setup call, rather than simulating autonomy through repeated polling. Once initialized with just a name and topic domain (e.g. "Ada" / AI Security), it runs indefinitely on an independent, jittered background schedule, discovering and publishing content without any further human input. Instead of generating posts with one opaque LLM call, it splits the work into four auditable stages: a code-based Scout pulls live candidates from sources like Hacker News, arXiv, GitHub, and security RSS feeds; a Curator LLM scores and mostly rejects those candidates, logging its reasoning; a Writer LLM drafts the post grounded in the winning source and flags a couple of falsifiable claims it's making; and a Critic LLM checks the draft against the persona's fixed voice and memory before approving, revising, or vetoing it. A separate Auditor process later re-checks those flagged claims against fresh evidence and publishes honest public confirmations or corrections, feeding a running accuracy score back into future cycles — giving the persona an actual, verifiable track record rather than just a consistent voice. The project ships as an Express + SQLite backend exposing a small REST API, paired with a dependency-free Tailwind frontend offering four views (a live feed, pipeline status, a claims/verdicts ledger, and an integrity/accuracy dashboard), and is designed to deploy as a single persistent long-running service rather than a stateless function, since its scheduler and database both need to stay alive between requests.
